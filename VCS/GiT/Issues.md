# Git Issues

Issues sind Aufgaben, Fehlerberichte oder Ideen, die direkt auf Plattformen wie GitHub oder GitLab dokumentiert werden. Sie sind kein Git-Feature, aber ein zentraler Teil des Arbeitsablaufs.

Jedes Issue hat einen Titel, eine Beschreibung, Labels zur Kategorisierung (z. B. Bug, Feature) und kann einer Person zugewiesen werden. Jedes Issue bekommt eine Nummer wie #42.

Schreibt man in einer Commit-Nachricht `Fixes #42`, schließt GitHub das Issue automatisch, sobald der Commit in den Hauptbranch gemergt wird.

Mehrere Issues lassen sich zu einem Meilenstein zusammenfassen, um den Fortschritt auf ein größeres Ziel hin zu verfolgen.
