# Virtualisierung

**Virtualisierung:** Auf einem echten Computer laufen mehrere virtuelle Computer gleichzeitig.

**Virtuelle Maschine (VM):** ein kompletter Computer, nur als Software. Jede VM hat ihr eigenes Betriebssystem.

- **Host:** der echte Computer
- **Gast:** das Betriebssystem in der VM

**Vergleich:** Ein Haus mit mehreren Wohnungen. Jede Wohnung ist getrennt, alle stehen auf demselben Fundament (der Hardware).

## Vorteile

- **Kosten sparen:** weniger Server, Strom und Platz
- **Sicherheit:** VMs sind getrennt. Stürzt eine ab, laufen die anderen weiter.
- **Snapshots:** Zustand speichern und bei Fehlern zurückspringen
- **Flexibilität:** VMs in Minuten erstellen, kopieren und verschieben
- **Bessere Auslastung:** Die Hardware wird voll genutzt.
