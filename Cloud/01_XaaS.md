# XaaS – Anything as a Service

**XaaS:** Oberbegriff für IT, die als Dienst über das Internet bzw. die Cloud angeboten wird.

| Modell | Was bekommt man? | Beispiel |
| --- | --- | --- |
| **SaaS** – Software as a Service | fertige Software im Browser oder in der App | Microsoft 365 |
| **PaaS** – Platform as a Service | Plattform, um eigene Programme zu entwickeln | Azure App Service |
| **IaaS** – Infrastructure as a Service | Server, Speicher und Netzwerk zum Mieten | AWS |

## Wer verwaltet was?

| | SaaS | PaaS | IaaS |
| --- | --- | --- | --- |
| Anbieter | alles | Infrastruktur und Plattform | nur Infrastruktur |
| Benutzer | nichts | seine Software | Betriebssystem, Software und Daten |

**XaaS vs. SaaS/PaaS/IaaS:** XaaS ist der Oberbegriff. SaaS, PaaS und IaaS sind spezielle Arten davon.

## Vorteile

- schneller neue Technik nutzen
- von überall arbeiten
- weniger eigene Geräte und Server
- einfachere Abläufe, weniger Kosten
